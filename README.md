## 👋 Sobre mí

Me dedico al desarrollo web construyendo soluciones completas de principio a fin: desde interfaces interactivas y fluidas hasta el diseño de esquemas de bases de datos, seguridad y despliegue en servidores.

* 💻 **Frontend:** Desarrollo modular con **TypeScript, Next.js, React y Angular**. Me gusta cuidar la experiencia de usuario integrando animaciones fluidas y entornos 3D (**Spline, Framer Motion**).
* ⚙️ **Backend y Datos:** Construcción de APIs robustas y seguras con **Java (Spring Boot)**, **Node.js (Express)** y **PHP (Laravel)**. Modelado de datos relacionales con **SQL (PostgreSQL, Oracle, Supabase)** y no relacionales con **MongoDB**.
* 🐳 **Infraestructura y Entrega:** Entornos reproducibles con **Docker**, migraciones controladas y despliegues automatizados mediante pipelines **CI/CD**.
* 🛠️ **Calidad y Arquitectura:** Gestión eficiente del estado asíncrono y global (**TanStack Query, Zustand**) respaldada por pruebas unitarias y E2E (**Playwright, Jest, Testing Library**).
* 🤝 **Trabajo en equipo:** Metodologías ágiles (Scrum), control de versiones limpio con Git y capacidad para trabajar con documentación técnica en inglés (B2).
